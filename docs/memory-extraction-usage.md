# 记忆提取与用量记录（0.2.3）

## 行为

自动提取使用 v2 提示词，字段规范由实际校验模型生成，并提供有效 JSON 示例及来源映射说明。校验、来源和版本保护保持严格；候选仍需人工确认。

记忆提取单独使用非流式 Chat Completions 调用，DeepSeek 官方接口启用 JSON Object。聊天和其他原有流式调用保持原路径。无自动 HTTP 重试，模型调用超时仍为 90 秒。

每次请求冻结请求模型和 API 提供商域名，保存响应模型、终止原因及接口返回的输入、输出、总 token。缺失值为 null；只有输入和输出都已返回时，才计算缺失的总数。格式失败也保留已返回用量。历史用量未知，不用字符数估算。

中断后复用已保存输出的新处理任务指向原任务；用量不重复计入。被截断的输出不能通过中断复用绕过校验。

## 页面与接口

工作上下文 → 长期记忆 → 提取记录；当前进展的自动提炼面板也提供入口。默认当前清单和最近七个本地自然日，支持全部清单、时间、模型、提供商、状态筛选，每页 20 条。

GET /api/v1/knowledge/auto-memory/jobs 仅限 owner：
- topicId：inbox（默认）、all 或清单 ID。
- from/to：ISO 时间，开始包含、结束不包含。
- model/provider/status：精确筛选。
- cursor/limit：非负偏移及 1–100 条页长，默认 20。

返回 items、total、nextCursor、summary、filters。汇总覆盖全部匹配记录，未知不当作零，复用不重复统计。不返回输入快照、模型正文、API Key 或完整接口 URL。

## 历史恢复和迁移

新增字段为可空字段或有默认值的字段，不删除旧记录。旧任务的 usageStatus 为 legacy，模型身份和用量均未知。

每个有效、可读的旧来源按当前 hash 检查最新提取结果。只有 v1 格式失败会解除阻塞并进入原串行限频队列；其他错误不自动重试。来源记录 formatRecoveryVersion，重启不会重新解除已经检查过的阻塞。暂停、归档范围恢复可用后再检查；变化或删除的来源走原有扫描规则。

## 验证

服务端单测、迁移演练覆盖格式、来源、用量、分页汇总、权限、旧失败恢复及截断输出中断复用；浏览器覆盖桌面与移动端统计页面和原全局 AI/审核流程。

发布前另用服务器当前 DeepSeek 配置和已有来源进行只读模型验收：返回格式及证据均通过。部署后的真实任务用量与安装、资源一致性检查保存在本轮交付记录中。
