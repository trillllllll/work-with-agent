# 本地优先同步交付

2026-10-26，Dovun 0.5.0。以 TR4 的本机副本＋共享工作区方案替换每日模式选择。

- 桌面直接打开本机副本。手机首次联网登录后也可离线新增、修改、完成任务，刷新保留，重连自动补传。
- 任务、清单、标签使用持久队列、永久回执、字段冲突及缺号重取基线；完成时间等历史元信息保留。
- 聊天、资料、记忆和执行控制访问同一云端；已读取内容和附件按工作区缓存。未下载原件、上传和模型调用需要联网。
- CLI 与代码留在本机。云端统一调度；切换绑定前等待旧后台写入结束，未结束执行会阻止切换。
- MCP 保留连接自己的范围和审批；同步凭据不替代外部 MCP 凭据。已确认吊销后不能通过断网缓存恢复访问。
- 三源数据库只在一致副本上合并。同主键差异、唯一冲突的依赖及历史执行保存在可分页读取的迁移档案中；不重放历史执行，不复制连接凭据。
- 本机历史未确认迁入时拒绝绑定。经核对的旧草稿只复制一次，不覆盖新草稿、不重放旧请求。
- 文件校验独立执行：附件、任务图片与旧文件产物逐项核对内容摘要；旧产物改为可移植的附件引用。

## 验证

全量自动化回归、生产浏览器离线测试、桌面 Rust 测试及翻译/构建检查均为发布门槛。真实本机 Codex 经 NodeAgent 回传已验证，重启无重复；真实 index.ts 验证已绑定副本不会启动本机调度。

三源演练：153 条任务、77 段对话、231 份资料；698 份差异/历史记录归档；14 个引用文件校验通过。完整快照恢复后数量、数据库完整性和关系检查一致。正式切换前重新冻结并取一致备份，不以演练副本覆盖切换前的新修改。

## 发布顺序

更新 app-knowledge 并提交全部源码 → 完整验证 → 推送 → 构建桌面和服务器候选 → 安装备份与资源核验 → 冻结旧写入并重新合并 → 候选验收 → 公网切换。旧源码、环境、应用和数据保留恢复副本；安装与正式数据迁移分别核验。

服务器 Dockerfile 增加 scripts 目录，供客户端边界检查使用。无 CI 工作流变更。新增 sync_workspace、sync_imports、sync_import_archive 数据库迁移。
