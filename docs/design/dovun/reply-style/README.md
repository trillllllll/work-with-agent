# 内置助手回复风格配置

在“设置 → 模型与 AI”增加独立的“回复风格”配置。默认只有：**结论先行，多用短句。**

- 可编辑、留空或恢复默认；恢复默认后点击保存。
- 最多 1000 字，前后空白会去除。留空不附加风格要求。
- 单独保存，不需要配置模型或测试连接，不覆盖模型密钥和其他设置。
- 保存后从下一条消息起采用新配置。处理中请求复用已持久化的上下文。
- 只影响表达偏好；权限、审批执行和回复语言仍沿用现有规则。
- 同类控件复用公共 Textarea、Label、Button、Skeleton 和设置加载错误组件。

## 实现与升级

使用 `app_settings.reply_style` 保存全局偏好；migration `20261030000000_reply_style` 只新增带默认值的列，不重建表、不改原有业务记录。

`GET /api/settings/reply-style` 读取当前值和默认值；`PATCH` 只接受 `replyStyle`，使用现有 owner 鉴权和 CSRF 保护。每次新请求组装系统上下文时读取，计入系统提示词 token。

应用功能知识已同步；版本沿用 0.4.0。
