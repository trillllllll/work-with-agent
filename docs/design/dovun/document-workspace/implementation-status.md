## 源码交付

1. **资源与兼容。** 复用 Material/MaterialVersion 身份；固定版本引用、请求回执、正文与整理版本分离。旧文本接口不能覆盖富文档；旧证据 hash、旧任务图片身份和权限保持可追溯。人工与 AI 共用版本、权限和引用校验，AI 修改仍走提议确认。
2. **编辑与恢复。** 产品 `richdoc-v1` 与 Tiptap JSON 显式转换，共用任务基础编辑扩展。会话独立于视图，拥有草稿、上传、撤销与冲突；旧回执不覆盖新输入，未知结果先查回执，拒绝写入不自动重放。输入缓冲在离开前同步交给会话；转换失败另存原始编辑器状态，防止新视图把它清掉。
3. **统一工作区。** 多标签、双栏25–75比例、目录、文件信息、历史、任务关联和手机全屏布局。旧资料、任务资料、工作上下文、搜索与来源入口收敛；确切历史只读，恢复生成新版本。
4. **文件与格式。** 图片/通用附件插入与复用，100 MiB上传、IndexedDB字节恢复、上传结果只回原会话。Markdown批次相对路径映射随版本保存；缺图可补充，移动改名不破坏引用。旧原件与补充说明分别可读。已确认版本可“另存为”新格式副本，显示损失并记录确切来源，不覆盖源文档。
5. **阅读。** Markdown源码/阅读/分屏、代码高亮、图片、PDF页码/目录/搜索/阅读位置、DOCX结构、XLSX工作表/坐标/合并单元格。实际解压、XML和工作表几何预算先于Office解析，超限保留原件下载。
6. **导出。** 完整文档包保留正文、确切依赖、来源字节及校验和；再导入创建新身份。独立本机恢复包保留草稿、冲突、待核查请求、原始失败编辑器状态和附件；缺字节明确标为不完整，超预算可逐附件下载。
7. **迁移与回滚。** 增量迁移可重复执行，旧表和字节保留；兼容读取代码可通过 `DOVUN_DOCUMENT_READ_ONLY=1` 暂停新旧资源写通道。回退不以旧数据库覆盖新增数据。
