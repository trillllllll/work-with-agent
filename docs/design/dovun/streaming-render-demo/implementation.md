# 正式对话渐进渲染

范围：基于本地 `08a9c84` 实现，并按用户指示提交源码、测试与功能说明；不包含打包、安装或发布。

## 已实现的行为

- 正式聊天的结构化文字与普通文字共用 Markdown 组件。已经闭合的 Mermaid/SVG 围栏可显示；未闭合围栏只显示代码。
- 柱状、折线、饼图、散点与多系列收到完整数据项后更新，同一页面的 ECharts 实例持续复用。预览始终未核验；最终 `block_commit` 继续经过来源与数量校验。
- Mermaid/SVG 约每 160 ms 取最新候选，完成当前异步渲染后才处理下一候选。失败保留上一张安全图形，最终渲染状态独立于传输结束。Markdown Mermaid 与结构化 Mermaid 共用配置与渲染队列。
- `renderMode: "fragments"` 的 HTML 只追加完整、清理后的顶层片段。用户输入、焦点和滚动由原 DOM 保留；源码查看仅隐藏预览。主题通过桥消息更新。最终服务端校验后，每个 iframe 实例执行唯一的末尾普通初始化脚本一次。
- 分段 HTML 不支持完整文档标签、外部样式导入、外部/模块/嵌套脚本及内联事件。遇到不支持的结构保留已有预览并提示，不重建 iframe。完整文档与历史 HTML 沿用原路径，现有 CSP、CDN 白名单、导航防护、懒加载和只填入不发送规则保留。
- 输入状态只在同一个打开的 iframe 中保留；刷新、切换会话、重新创建全屏实例仍按原行为重建。
- HTML 懒加载在父级恢复滚动位置后重新检查 300px 预加载范围，避免使用旧布局的交叉观察结果。贴底区分布局造成的位移和用户操作；用户上滚与内容增长同时发生时仍保持阅读位置，回到底部后恢复跟随。

## 协议与恢复

原 SSE 事件序号与数据库事务不变，内容保存在现有 `blocksJson`，不新增表或迁移历史记录。

| 事件 | 数据与应用条件 |
| --- | --- |
| `block_source_delta` | `blockType`、UTF-16 `offset`、`delta`、可选 `renderMode`；前缀一致才追加 |
| `block_chart_preview` | 从 1 递增的 `revision`、绝对 `previewSpec`；只含完整数据项，来源标未核验 |
| `block_commit` | 最终服务端校验后的完整块，原客户端仍可消费 |
| `block_error` | 保留累计源码/图表预览，标记未完成 |

重复偏移/版本忽略，冲突或事件序号缺口请求带事务水位的快照。恢复期间暂存事件，按 run/seq 回放水位后的内容。消息或内容块进入终态后不接受增量。原执行权检查仍覆盖每次持久化；停止、租约失效后迟到内容不能写入。

源码沿用 100 ms/约 2 KiB 的 TextBatcher。图表快照约 100 ms 合并，慢写期间只保留最新待写快照，不排队保存过期候选。无变化的 HTML/图形候选不重复清理或重画，HTML 最终确认后停止定时处理。

## 学习帮助与来源

来源编号沿用消息上的实际来源快照，图表预览不能声称已核验。完整可展示的 SVG/HTML 片段和图表预览沿用同事务的学习帮助记录；半截标签、仅样式/定义资源不算已提供帮助。文字的 `studySupport` 晚于正文到达时也会保存，断流不会漏掉 solution 标记。

Mermaid 的真实解析发生在浏览器，不能仅凭服务端语法策略推测已经出图。因此安全候选渲染成功后，客户端通过 `POST /api/messages/:id/block-preview` 回报实际候选前缀，服务端校验消息、块、请求归属后按原事件键幂等记录帮助。空图头不回报；每个挂载块最多一次初始尝试加两次重试。此接口不修改消息或分数，也不是模型工具；共享工作区通过精确 owner relay 路径转发到权威数据端，并跳过无关任务同步。

## Demo 复用

实验页保留播放速度、单步、断流和原始输入等控件，解析器改为正式 ReplyParser 的兼容适配器；Markdown、Chart、渐进 SVG/Mermaid 和 HtmlFrame 与正式聊天共用。`markup.ts` 仅重导出公共片段扫描器。

短回复不保证在传输结束前出首图。验收的是完整内容及时更新、最后一个片段正确进入结果、输入稳定与恢复无重复丢失。模拟模型测试不等于真实供应商、本机已安装应用或线上验收。
