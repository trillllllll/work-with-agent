# 流式渲染实验结果

本文保留最初独立 Demo 的实验记录。后续正式对话接入、共享组件及最新验收见 [正式实现说明](./implementation.md)。

2026-11-07，本机源码基线 `08a9c84`。实验代码为本次新增的独立 dev 入口，正式前后端逻辑未接入；没有安装或部署应用。

## 结论

五类内容都可以在生成期间更新。固定样例在 32 字节、0.5× 慢放下，桌面和手机模拟视口均在回复结束前产生可见结果。快速到达的小段内容不保证提前出现首图：128 字节、4× 的 Mermaid 样例在传输结束后才完成首次排版。这是实际测得的边界，不能宣传为「任意内容每个 token 都实时可见」。

Demo：<http://127.0.0.1:5186/streaming-render-demo.html>。支持五类内容切换、调速、分块大小、暂停/继续、单步、中断、重放、等完整内容再渲染的对照、错误图形保留上一版，以及浅色/深色。

## 一次本机观测

从首个分块开始处理计时，到首个可见结果；非模型性能基准。每项使用新的浏览器页面，浏览器进程和开发服务器缓存可共享。精确值会受机器负载、模块加载和播放设置影响。

| 类型 | 32 B / 0.5× 首次可见 | 成功更新次数 | 128 B / 4× 首次可见 | 快速输入结束前可见 |
| --- | --- | --- | --- | --- |
| Markdown | 0.15 s | 17 | 0.03 s | 是 |
| Chart | 1.57 s | 6 | 0.06 s | 是 |
| Mermaid | 1.21 s | 2 | 0.18 s | 否 |
| SVG | 1.41 s | 8 | 0.10 s | 是 |
| HTML | 5.05 s | 4 | 0.17 s | 是 |

HTML 样例将较长的完整 style 放在首屏结构之前；慢放中先等到样式及 header 闭合，所以首次可见较晚。正式集成可把通用样式预置，或先输出首屏结构。成功更新次数是渲染提交/图片 load/iframe 确认的观测数，不等于 token 数或绘制帧数。切换渲染方式会重建预览并重新统计，不能把两种方式的计数当成一次连续实验。

十次观测均无页面 JavaScript 异常、失败请求、业务 API 调用或外网请求。HTML 的控制台有共享 `buildCsp` 产生的 `Unrecognized Content-Security-Policy directive 'webrtc'.` 兼容提示；本次保留原共享策略，没有将它宣称为浏览器支持的防护能力。其他沙箱限制仍在，Demo 只验证固定可信脚本。

## 实验中修正的问题

1. 每个片段都取消 Mermaid 异步排版，会让渲染一直追不上输入。改为单个异步队列：完成正在处理的候选，再取最新候选，约 160 ms 采样。
2. 「收完输入」不等于「渲染完成」。现在单独等待最终渲染确认，才显示生成完成。
3. 共用 VisualFrame 切换源码会卸载子组件，导致 HTML 状态重置。实验将源码固定放在旁边，预览在同一个 iframe 内持续追加。
4. 独立页面遗漏了响应式表格样式，导致桌面表格和手机记录同时出现。补上现有 conversation.css 与具名容器，并新增可见性断言。
5. HTML 的按钮先保持 disabled，整个回复校验完成后，脚本安装一次监听并启用按钮。

首轮浏览器计数断言曾把含「次」的文本整体转成 Number，得到 NaN；已修正测试。早期边修改边跑造成的热更新中断不计入最终通过结果，最终回归期间未编辑页面源码。

## 正式接入仍需完成

- 后端为 source / chart 发布增量事件，带块 ID、offset/revision；处理去重、缺片、停止与重连重放。
- 保留完整块的服务端校验、图表来源核验与持久化，不能以预览通过代替最终校验。
- HTML 实验只追加完整顶层片段；任意父元素的持续修改、DOM diff、外部脚本、模块脚本、事件副作用和通用安全需单独设计。
- Mermaid 目前仅验证流程图，其他语法需增加边界案例；SVG 必须继续走现有安全策略。
- 长文档、大型图形、低性能设备需要实际预算与性能验收。当前累计字符串会重复解析，尚未验证大规模性能。
- 复用正式 HTML 的导航防护、配置开关和生命周期管理；本实验没有替代这些能力。
