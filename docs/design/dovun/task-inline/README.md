# 单行任务卡片

基准：任务密度 demo 的 inline-3 默认 48px 卡片；沿用控件统一后的浅深色材质、14px 标题。基线为 codex/dovun-workspace / 28e6a28。原 demo 不变。

## 已实现

- 所有共享 TaskList 入口采用 48px 单行卡片，间距 5px、圆角 10px。只改变列表展示，不改变任务正文、排序规则和业务接口；看板、四象限、日历及详情编辑器保持原布局。
- 按实际任务内容区宽度测量标签：完整名称 → Unicode 首字素 → 能容纳的前几枚首字和 +N。标签颜色与顺序保留；点击/键盘打开完整标签浮层，悬停及焦点可看完整名称。
- 优先级、特殊状态和清单来源在窄区域缩写，多项时合并提示。极窄的内容区把元信息并入同一个标签浮层，为标题和日期让位；完整元信息保留在提示、可访问名称与浮层中。
- 普通日期为月/日及开始时间，当天安排显示开始时间，跨日加 ↗；完整年份和时间段保留在提示、time 的 datetime 及原详情中。
- 子任务缩进为 24px，拖动投影同步调整。父子任务和拖动预览均保留单行布局，AI 与菜单在拖动预览中使用等宽占位。
- 使用隔离测量探针，不复制可访问文字，不重挂载编辑器；ResizeObserver 只调度下一帧测量，布局状态不反过来改变探针的固有宽度。
- 标签/信息/日期浮层的文字及留白都拦截指针、鼠标、触屏和点击冒泡，防止误开任务或触发拖动。复选框保留 18px 图形，外层命中区为 26×40px。
