# Dovun 个人工作台可点击样板

打开 [index.html](index.html) 体验新的个人工作台视觉。它独立运行，不读取正式应用的服务、凭据或数据。

## 可以体验

- 今天：添加、完成任务，打开详情编辑标题、正文和时间，关闭或刷新后重新查看。
- 规划：日与周视图、日期切换；已安排的演示任务显示在对应日期，点击打开详情。
- 资料库：搜索标题与正文，按类型筛选，添加文本资料，查看原文。
- 工作上下文：当前简报、已确认记忆、固定说明和来源预览。
- AI 面板：页面范围与任务范围、模拟回复、接受或放弃演示提议；跨页面保留当前演示会话。
- 顶部控制：中英文、浅深色，以及正常、空、加载、错误四种预览状态。
- 手机：五个底栏入口、更多分组、全屏助手、任务详情及键盘焦点管理。
- 设置中的品牌图稿：查看纯色、单色、反白及小尺寸图标。

演示日期固定为 2026 年 10 月 23 日。所有更改只影响演示数据。任务保存在本标签页 sessionStorage 中；新增资料和聊天刷新后重置。非核心入口明确展示为导航位置说明。

## 验证

在仓库根目录使用 Node 22 运行：

```sh
node docs/design/dovun/prototype/verify.mjs
```

脚本复用仓库已有的 Playwright 和 sharp，无需启动数据库或应用服务，也不调用外部网络。

重新导出图标可运行 `node docs/design/dovun/prototype/generate-assets.mjs`。ICNS 使用 macOS 内置 iconutil 生成；其他平台可生成 PNG、ICO 和 iconset。

检查结果：[qa-report.json](evidence/qa-report.json)。截图保存在 [evidence](evidence/) 中，包括桌面、手机、深色、英文、任务详情、资料库、规划、工作上下文和 AI 面板。

独立审查记录：[review.md](evidence/review.md)。长标题、日期分类、晚间安排与键盘焦点问题已修复并复核。

这批验证针对独立样板。正式应用、真实模型、迁移、安装包、本机安装和公网部署尚未验收。
