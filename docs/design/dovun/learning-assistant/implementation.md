# 对话学习与学习主图

本轮完成 `codex/learning-assistant` 的剩余功能。参考学习助手 v3 Demo 的业务范围：在对话里讲解和正式练习，在学习档案里查看笔记、主图和历史，也保留原有自主练习入口。

## 完成的行为

- 学习助手可切换主题；打开该主题最近更新的对话，无历史时开始绑定该主题的新对话。创建主题的提议批准后，原先未绑定的学习对话会绑定新主题。旧会话以服务器保存的绑定为准，包括未绑定状态。切换中的迟到响应不能覆盖新选择、工作助手或新发送。
- 主题可保存一张经确认的 SVG 主图。前后端使用既有 SVG 安全规则，标记只能指向本主题的有效知识点。同批创建支持占位引用；更新检查主图版本和预览时的主题结构。
- 主图按保存的四档掌握状态着色，可点选或键盘定位知识点。支持分组中的路径、圆形等形状，也支持直接标记形状自身。相同 SVG 内容保持稳定，避免父组件重绘清除应用加上的状态和无障碍属性。
- 助手顶部主图入口和非输入状态下的 M 快捷键打开主图；学习档案也可展开同一张主图。档案跟随助手的主题选择，普通浏览档案不会改绑已存在的聊天。
- `show_learning_card` 只引用真实知识点、主图、生成任务或正式练习；工作助手不可使用。卡片经运行租约检查后事务保存，按消息与工具调用 ID 幂等生成，实时事件和历史快照使用同一份卡片。
- 练习卡片复用原生 `PracticeSetup`、`PracticeSessionView` 和正式学习 API。用户采用候选、填写及提交答案、判题、暂停续做、重做和复核均沿用原权限、版本与持久化规则；助手不能代替用户提交。
- 采用请求按任务保存原请求 ID；会话操作和答案的未知提交也保留原请求。恢复完成前禁止新操作；恢复失败明确提示重试，不把未知记录当成空记录覆盖。
- 对同一工作区的相同练习或生成任务，仅允许一个可写编辑器；其他位置提示先收起原编辑器再重试。支持 Web Locks 的浏览器同时保护跨标签编辑。组件退出后等待进行中的持久化及请求结束才释放编辑权。历史已采用卡片默认收起，点击后恢复正式记录。
- 当前主题简报读取已保存的确认收尾、最近 5 次作答、最多 5 条到期复习及 3 个未完成练习；界面和助手上下文共用读取服务。无记录时明确说明，不推测昨天的进度。新主题的发送前预估也包含该主题上下文。

## 数据兼容

新增学习主图、可空会话主题绑定和主图结构指纹迁移。旧会话保持未绑定；旧主图缺指纹时提示更新。结构指纹覆盖有效节点 ID、父节点、类型、标题和顺序，笔记和掌握状态的日常修改不会单独使主图过期。结构指纹同时纳入审批前置条件，审批期间结构变化不会将旧图误标为最新。

内置功能手册位于 `server/src/agent/app-knowledge.ts`，本轮已更新。开发与合并阶段没有修改版本号，也不执行安装、发布或用户数据迁移；后续双端发布记录见 [release.md](release.md)。

## 验证与复核

- 全量单元测试：服务端 125 文件 / 1080 项通过，客户端 96 文件 / 586 项通过。
- 新专项浏览器测试：`playwright.learning-assistant.config.ts`，三种浏览器项目共 15 项通过。覆盖真实 UI/API/SQLite/worker 链路；模型传输为确定性 fixture。
- 专项验证包括重复练习卡片、跨窗口编辑互斥、已保存但响应尚未返回时关闭编辑器、保留原请求 ID 续交、延迟 IndexedDB 恢复、主题选择乱序及身份切换、卡片快照恢复、主图键盘与手机输入焦点、路径与直接标记形状的深浅色着色。
- 原有学习流程 63 个唯一组合场景均有通过证据（首轮 59/4，空态标题修正后三端补测 6/6）；前后端构建、文案与公共控件检查通过，独立复核 Approve。详细记录及边界见 `verification.md`。

本轮不把浏览器模拟验收当成物理手机、真实模型教学质量、实际云端账号配对或已安装桌面应用验收；没有读取真实模型凭据，没有推送或部署。
