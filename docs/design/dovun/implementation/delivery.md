# Dovun A/B 改造交付记录

2026-10-23。源码与 macOS Apple Silicon 候选包已完成；没有覆盖安装、服务器部署、仓库改名或域名切换。

## 视觉与产品

A 瓷白浅色、B 石墨深色共用真实应用布局，分层底板/工作区/任务与详情/输入浮层；已推广至今天、规划、资料、工作上下文、设置和其余原有页面。Dovun 归栈宽缝图形用于侧栏、启动页、favicon 和桌面图标。导航共用有序配置，高级工具默认折叠，已有偏好保留。

右栏复用同一任务编辑器与聊天实例。切页、资料/上下文页签、助手展开收起保留草稿；未配置模型时提供真实配置入口，不生成虚构建议。今天新增仍按真实日期和收集箱规则执行。

[真实截图对照](index.html)覆盖中英文、浅深色、1586×992、1440、1280、1024 和 390px；无整页横向溢出或 pageerror。截图来自隔离 API 与实际组件，英文截图另核对 `html.lang=en`。图库的主题、参考图及英文切换已验证。

## 发布边界与剩余限制

本轮没有用真实用户数据库或 profile 做迁移试验，没有启动或替换已安装的应用，没有改服务器文件或数据。macOS 证据包括打包身份、原生编译/逻辑测试、独立审查和真实 WebKit 隔离 profile 恢复；没有把这些表述成已安装应用的升级验收。Windows 仅做路径与迁移逻辑测试，缺少 Windows WebView2 原生升级与安装运行证据。

大 chunk 提示和既有 Rust unused-function 提示不阻止构建；macOS 仍为 ad-hoc 签名且没有公证。新名称/图形的法律注册或商标授权不由本次实现验收确认。

后续真实安装与部署按 [迁移手册](../../../dovun-migration.md)及仓库 AGENTS.md 执行，分别记录数据摘要、版本和公网资源。已有 MCP 和同宿主连接只更新原条目，不新增第二条。
