# Token 对比

隔离固定场景重放，统一使用 mixed-text-v1 文本估算，**不是供应商实际计费**。累计输入包含加载能力产生的额外调用和摘要请求。长会话固定摘要来自已知测试事实；语义与审批行为另外由单元和端到端测试验证。

| 场景 | 优化前估算输入 | 优化后估算输入 | 减少 | 调用次数（前→后） |
| --- | ---: | ---: | ---: | ---: |
| 普通任务查询（完整两次调用） | 24,519 | 7,651 | 68.8% | 2 → 2 |
| 长会话与大工具结果（稳定摘要） | 59,645 | 13,308 | 77.7% | 2 → 2 |
| 首次压缩（两边均计入摘要请求） | 66,732 | 20,395 | 69.4% | 3 → 3 |
| 创建及审批后续办 | 24,557 | 12,969 | 47.2% | 2 → 2 |
| 未预选修改能力（计入额外加载调用） | 24,526 | 16,785 | 31.6% | 2 → 3 |
| 明确要求可视化（保留完整展示能力） | 12,216 | 7,076 | 42.1% | 1 → 1 |

富媒体、修改需要时仍加载完整对应定义。首次压缩有额外成本，短会话不会调用摘要模型；不承诺所有请求都节省同样比例。脚本不调用模型，不读取用户数据库。可用 `node scripts/context-token-benchmark.mjs` 重放（先构建服务端）。
