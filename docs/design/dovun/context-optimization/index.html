实现与验证

实现边界
  • 普通请求不携带完整修改及富媒体协议。
  • 按需加载不扩大权限，业务修改仍先预览、确认。
  • 工具可用范围随运行游标保存，中断恢复不提前放行。
  • 历史原文、附件和富媒体保留，可分页回读。
  • 容量未知时不虚构上下文上限和空闲空间。
验收记录
  • 独立审查问题均已修复并补回归。
  • Chromium / 手机 / WebKit 浮窗与审批链路通过。
  • 浅深色、1586 / 1280 / 1024 / 390px、中英文通过。
  • 完整测试：841 服务端 + 375 客户端；浏览器核心 38 通过 / 12 原有跳过；构建、语言和公共控件检查通过。
