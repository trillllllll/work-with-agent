# Dovun 上下文优化

源码与隔离验收已完成，沿用 `codex/dovun-workspace` 和 0.4.0。2026-10-24 用户追加授权提交、推送和覆盖本机 Dovun；不部署服务器。当前本机发布状态见 [发布记录](release.md)。

- [可视交付页](index.html)：真实浅深色、桌面与手机截图、对比表。
- [Token 对比](token-comparison.md) / [原始估算记录](token-comparison.json)。

## 已实现

工具保留少量常驻读取能力和能力目录，以 `load_tools` 加载所需组；明确意图会预选，`get_change_schema` 成功时也加载对应修改定义。`propose_changes` 仅提供已加载 family 的原有完整 schema，富媒体定义与详细规则按需加入。加载不代表授权，不执行修改。服务端仍走原来的提议编译、版本、预览哈希、用户确认与回执流程；混合修改必须先加载全部所需类型。

当前 assistant 获得的工具组随游标保存为 `offeredToolGroups`；同批加载和中途恢复都不能提前使用新组。新能力只在下一模型轮生效。旧的进行中请求保持原全能力范围，新用户请求改为按需；技能启用目录仍按原请求冻结。

历史按完整用户轮次分配约 4000 文本估算 token 的软预算，滚动摘要上限约 1000。大工具结果提供有效 JSON 摘录和原消息 ID；`read_context_source` 仅回读当前会话，按 UTF-16 offset/limit 分页，最大 2000 字符；返回页不会再被投影裁短。`conversation_search` 也可按 ID 回读当前会话的邻近原文，不再把“同一会话”误当成“还在模型窗口内”。原始消息、富媒体和附件均保留。

每轮发送前重新检查预算，保持当前用户正文和活动调用链完整；超预算会在浮窗标明，不静默丢弃或拆开调用与结果。摘要失败有带来源 ID 的摘录回退，不生成虚假决策；未加载的旧细节须回查。摘要和压缩标记在同一事务提交，以摘要版本 CAS 避免并发覆盖。

浮窗复用 Button、Popover、Disclosure；显示最近模型请求的组成柱状图、图例、估算 token/占比和已加载工具明细，以及本次 run 所有调用及摘要调用的累计数据。流式事件更新，快照恢复，不为旧会话补造统计。

## 统计口径

- `mixed-text-v1`：ASCII 约 4 字符/token，其余按 UTF-16 单元估算；包含少量消息包络估算。不是模型 tokenizer，不是账单。与此前统一字符数除 4 的旧估算不直接比较。
- 每个类别的占比以最近请求的估算输入为分母。供应商只返回整次 usage，不能把实际计费归因给某个分块。
- 上下文容量未知，暂不显示上限、空闲空间或容量占比，不猜测 1M 等数值。
- 供应商 input/output/cache 与文本估算分开。未返回不是 0；部分返回注明覆盖不完整。缓存属于输入中的一部分，不与输入重复相加；存在未返回缓存数据的调用时累计缓存显示未知。
- 统计事件按 round 去重；摘要调用单独计一次，失败尝试及加载开销纳入累计估算。富媒体只统计收到的原始文本与工具参数，不重复计算展示投影。
- `baseline` 只代表同一消息窗口带全工具的静态对照，不代表完整历史优化或实际账单；完整方案对比见独立固定场景重放。
- 固定场景不是用户真实请求重放，不与之前 19029 的样本直接相减。首次压缩对比计入两边的摘要输入，额外发现工具的模型轮也计入。

## 限制

摘要有信息损失，不能替代原文；长期事实仍以已确认记忆与数据库为准。当前请求与活动工具链本身过长时允许超出软预算并提示。工具按需加载可能增加一轮延迟，复杂富媒体或跨领域修改仍需完整定义，不能承诺所有请求相同比例节省。验证使用隔离数据库和模拟供应商，供应商真实 tokenizer、缓存命中、费用及真实模型语义质量未实测。
