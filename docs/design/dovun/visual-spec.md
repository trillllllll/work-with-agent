# Dovun 工作台视觉样板规范

状态：2026 年 10 月 23 日，用户已否决本版视觉，停止推广。以下保留作为历史样板记录；新方向见 [图像生成视觉探索](visual-exploration/round-01/index.html)。

## 产品与布局

Dovun 是个人工作台。用户先处理自己的任务、安排和资料，AI 在当前工作的上下文中参与协助。样板保留今天和规划作为日常入口，不添加新的首页。

导航按日常、清单、积累、AI 协作和高级工具组织。搜索在顶部，设置、变更历史和回收站在底部。高级工具默认折叠，访问其中页面时展开。手机使用今天、规划、清单、资料库及更多五个入口。

桌面侧栏基准宽 224px，助手宽 344px；大屏分别为 240px、370px。低于 900px 时助手作为浮层，低于 720px 时导航改为底栏，助手全屏。规划周视图可以在自己的时间网格内横向滚动，其他内容不产生整页横向滚动。

## 视觉变量

变量以 [样板 styles.css](prototype/styles.css) 为准。目前只作用于独立样板，尚未替换应用的 `client/src/index.css`。

| 类别 | 约定 |
| --- | --- |
| 字体 | 系统无衬线，正文 14px，行高 1.6；手机文本输入 16px，避免输入时自动放大 |
| 间距 | 4px 为基础，常用 8、12、16、24、32px |
| 圆角 | 控件 8px，内容面板 12px，标签 5px |
| 浅色 | 背景 `#f5f6f8`，工作表面 `#ffffff`，侧栏 `#f1f3f6`，正文 `#242b37` |
| 深色 | 背景 `#191c22`，工作表面 `#20242c`，侧栏 `#1c2027`，正文 `#e5e9f0` |
| 品牌深蓝 | 图标及浅色主要操作 `#354d85`；深色操作使用 `#b5c8f1` 并配深色文字 |
| 品牌珊瑚色 | 图标 `#cf7659`；界面仅少量强调，不绑定任务优先级 |
| 语义色 | 成功、警告、危险分别有独立的前景及背景变量；用户清单颜色与品牌色独立 |
| 动效 | 按钮背景与文字 120ms 过渡；减少动态效果偏好下不启用 |

使用行、分隔线和适量面板组织内容，不给每条任务套大卡片，不使用大面积玻璃、渐变和阴影。阴影只用于浮层。

## 图标候选

[纯色 SVG](assets/dovun-mark.svg) 根据已选定的 [宽缝 PNG](assets/dovun-icon-wide-gap.png) 手工整理轮廓，保留三片结构、中央回折、两道缝和圆润外角。小尺寸检查后，两侧色片各外移 24 个源坐标单位，使 16px 下的三片仍可分开。它是可审查的矢量候选，不覆盖原始选定图。

- [单色 SVG](assets/dovun-mark-mono.svg) 与 [白色 SVG](assets/dovun-mark-white.svg) 用于单色与反白场景。
- [应用图标 SVG](assets/dovun-app-icon.svg) 使用浅色圆角底板，为桌面图标预留空间。
- `assets/exports/` 包含透明 PNG 的 16、24、32、64、128、256、512、1024px 导出，以及 ICNS、ICO、1024px 应用图和 macOS iconset。
- 桌面资源尚未替换；当前图形的反向搜图和商标近似检查尚未完成。

## 与现有组件的衔接

正式推广复用现有 React、Radix、Lucide 组件和交互，不新增 UI 依赖。

| 已核对组件 | 推广方式 |
| --- | --- |
| Button | 现有 default、outline、ghost、destructive 等变体映射到新变量，保留尺寸与禁用行为 |
| Input | 调整现有边框、背景和焦点样式，保留校验、输入和手机字号行为 |
| Dialog | 保留 Radix 的焦点管理、关闭和 Portal 行为，调整表面、边框与阴影 |
| TaskList | 只调整视觉和布局，保留现有排序、层级、拖动及自动保存调用 |
| 导航 | 正式实现时把分组提升为共享有序元数据，不再由各个页面分别维护 |

样板使用原生 HTML 控件独立演示外观和交互，不是上述业务组件的替代实现，也不接入生产 API。

## 样板内容与验证

演示日期固定为 2026 年 10 月 23 日。演示任务及编辑内容保存在本页 sessionStorage 中，存储不可用时退回内存。刷新保留当前标签页里的任务；资料新增和聊天仅在当前页面运行期间存在。AI 回复为固定模拟，不调用模型，接受提议只修改演示任务。

可体验今天、规划、任务详情、资料库、工作上下文和 AI 面板。其余入口用说明页标明位置，没有伪装成已完成的业务页面。空状态、加载、错误可从顶部选择；重试返回正常样板。

验收脚本与结果见 [样板使用说明](prototype/README.md)。自动检查与截图证明样板本身的表现，不代表正式应用的业务验收、数据迁移验证或安装部署完成。
