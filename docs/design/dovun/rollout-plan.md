## 后续技术迁移边界

| 项目 | 0.3.0 过渡版 | 0.4.0 完成版 |
| --- | --- | --- |
| 显示名称 | Dovun | Dovun |
| 包名与进程 | dovun、dovun-client、dovun-server | 沿用新名称 |
| MCP 名称 | 新连接 dovun；已有连接更新原条目，不重复创建 | 旧启动别名移除，迁移现有连接 |
| 环境变量 | DOVUN 优先，WWA 回退；冲突明确提示，不输出值或凭据 | 只接受 DOVUN |
| 数据目录与文件 | 新默认 dovun/dovun.db；旧数据停服、备份、完整复制及校验后切换 | 使用新目录；跳过过渡版的旧安装先迁移 |
| 系统应用标识 | 保留 app.workwithagent.desktop，准备浏览器状态转移 | app.dovun.desktop，启动工作区前恢复状态 |
| 桌面通信 | 新旧壳和网页在过渡版内兼容 | 移除旧运行时通信入口 |
| 存储与草稿 | 迁移偏好、会话恢复状态和 IndexedDB 草稿，保留 origin、用户、服务范围 | 使用新存储键，拒绝静默丢弃旧草稿 |
| 备份与正文 | 新导出使用 Dovun；继续读取旧备份和旧资料链接 | 持续支持内容恢复，不批量改写用户正文 |

迁移失败保留原数据，不切换到不完整的新目录；重复执行核对迁移记录；两边都有有效数据时让用户选择来源，不自动合并覆盖。不能只移动 SQLite：还需完整覆盖资料文件、执行记录、本机配置、浏览器偏好和任务草稿。

REST 业务路径、MCP 工具名称、对象 ID 和业务表结构不随品牌改名重构。原仓库地址、部署域名和服务器路径在实际切换前保持有效。
