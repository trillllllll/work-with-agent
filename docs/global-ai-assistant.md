# 全局 AI 助手：实现与验证

本轮范围：本地开发、构建、测试。没有安装、部署、提交或推送。

## 交互

- 每页顶栏、任务详情、资料正文和工作区弹层打开同一个助手；快捷键 `⌘⇧L / Ctrl⇧L`。
- 桌面右侧 400px。1024–1279px 打开助手时左侧导航收为 56px。任务编辑器通过稳定 portal 容器移动，保持编辑实例。
- 手机全屏，返回保留页面和草稿；安全区和 `visualViewport` 高度用于适配键盘。
- 关闭只收起。消息、输入、运行和待审核方案均由根部的 `useChat` 保持。
- 上下文可跟随或固定；建议问题只填入输入框，不自动发送。

## 上下文与读取

`ChatContextV3` 在 V2 基础上增加页面状态、真实筛选、多选对象、版本和主动附件。页面组件通过 `usePageContext` 发布状态。V2、旧请求和旧运行继续兼容，旧消息没有快照时显示“上下文未记录”。

每次发送复制上下文，服务端解析已保存版本并持久化到 `AgentRun.contextJson`。`user_context` 事件把服务端冻结结果回填对应用户消息。请求指纹使用稳定的原始请求，重连不因对象更新而改变原运行。

固定上下文保持对象和查询范围；任务和普通资料预览的新消息读取最新已保存版本，显式历史资料/记忆来源保留指定版本。选中任务优先于列表筛选；不确定范围时要求澄清。全局查询可显式绕过当前页筛选。

主动附件支持任务草稿、资料草稿和正文选区。按 Unicode 字符计数，单个 20,000、合计 40,000，超过时拒绝并提示。附件固定于添加时，通过原消息的运行快照参与后续回放、摘要、按消息读取和完整会话保存；不会自动写回业务正文。

## 应用知识和来源

`server/src/agent/app-knowledge.ts` 的功能目录随应用发布，并使用当前应用版本。提示词载入精简地图及当前页说明，`read_app_knowledge` 按需读取详细说明。

`read_page_state` 返回冻结的页面范围和必要状态。设置、连接等字段采用白名单；密钥、令牌及连接凭据不进入页面上下文。

`query_tasks`、`library_read`、`memory_read`、`conversation_search` 等沿用现有只读链路。新增全局记忆搜索、资料筛选、历史版本读取以及规划时间段状态读取。

来源只从实际工具结果生成，服务端核对对象和版本后保存。点击再次校验，使用原有任务打开及保存保护，或定位资料版本、历史消息、记忆原文、功能说明。删除及失效来源显示错误。业务修改仍需审核，审批对象不随页面切换而改变。
